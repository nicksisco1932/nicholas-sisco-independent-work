## How to use it

- Read the starter-program guide before performing a session. Select home or gym variations you can set up securely.
- Record exercise variation, load or band setup, sets, repetitions, rest and approximate repetitions left in reserve. Note uncertainty rather than inventing precision.
- At the next session repeat, reduce or progress one variable using the guide. Do not infer hypertrophy from a single stronger performance.

<aside class="callout"><h2>Worked example</h2><p>Supported row: 6 kg per hand, 2 sets of 10, about 3 repetitions left, 2 minutes rest. Next session: same load and setup, attempt 11 controlled repetitions only if similarly comfortable. If technique changes, repeat or reduce.</p></aside>

Allow roughly 8–15 minutes with the activity. Suggested prerequisite: [Strength is a task-specific ability](w04-understand.html).

## Establish a comfortable starting point

Use the starter guide’s setup and stopping rules. Choose a resistance that allows controlled repetitions with several more apparently possible. This is an estimate, not a challenge to prove your maximum. First exposures can use one set; add the second only when the session is manageable.

## Progress one variable

For a 6–12 repetition exercise, keep the load while building controlled repetitions. When both sets reach the top of the range on two sessions with the intended reserve, try the smallest available increase and return toward the lower end. If the increase disrupts control, return to the previous resistance.

## Record enough to learn

Write the variation, load, repetitions, rest and an effort note. For a body-weight movement, a change in support or range may be a larger step than expected. Progress is an option supported by repeated performance, not an obligation because a new week began.

- Write a rule for holding the load and a rule for reducing it.

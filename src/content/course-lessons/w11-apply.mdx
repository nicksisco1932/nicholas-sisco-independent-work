Allow roughly 8–15 minutes with the activity. Suggested prerequisite: [A useful check does not have to be maximal](w11-understand.html).

## Prepare as usual

Use the starter guide’s warm-up, stable setup and comfortable variation. Choose a normal day, not a day with concerning symptoms or unusual exhaustion. If the setup differs from the earlier observation, note it and treat the comparison cautiously.

## Stop at the plan

Complete the familiar target while keeping the intended reserve. Do not add repetitions merely because the activity is called a test. If control deteriorates, stop the set. The result includes that observation; it does not require a rescue repetition.

## Write the full result

Record load, repetitions, rest, range, effort and any changes. Compare with the earlier log. If conditions differed substantially, repeat the observation on a later suitable occasion instead of manufacturing a precise improvement percentage.

<aside class="callout"><h2>Worked example</h2><p>Earlier: eight chair squats with a comfortable reserve. Today: the same eight at the same chair height feel easier. The check ends at eight; it is not extended to failure.</p></aside>

## Try it

- Complete a paper comparison using the example or an appropriate familiar task.
- Record one condition that was consistent and one that could still influence the result.

Scenario alternative: Use the supplied chair-squat entries and write the conclusion you would report.

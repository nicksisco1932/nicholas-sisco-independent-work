Allow roughly 10–15 minutes with the activity. Suggested prerequisite: [Run a controlled progress check](w11-apply.html).

## Return to the progression rule

An easier check may support a small progression when the usual criteria are also met. It does not justify a sudden large increase. If the evidence is unclear, repeating the task is a valid next step.

## Make room for mixed results

A person can improve one task while another stays unchanged. Different movements, learning demands and accumulated fatigue can contribute. Avoid describing the whole body as a responder or nonresponder from a small log.

## Use the result to plan

Write a bounded conclusion, a next action and a review point. If the goal has changed, choose a task that measures the new goal. Progress checking should inform training rather than displace it.

<aside class="callout"><h2>Worked example</h2><p>Reese’s row becomes easier while split squats remain awkward. Reese uses a small row progression when criteria are met and keeps a supported split-squat variation for practice.</p></aside>

## Try it

- Write a conclusion that names the task and conditions.
- Choose a next action for each movement in Reese’s case.

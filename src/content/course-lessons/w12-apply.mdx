Allow roughly 8–15 minutes with the activity. Suggested prerequisite: [Periodization is a planning tool](w12-understand.html).

## Choose a small number of priorities

Pick one ability-based goal and one process you can control. An example is carrying a familiar load more comfortably while maintaining two appropriate weekly sessions. Avoid promising a specific muscle gain or fat loss based only on course completion.

## Specify the routine and fallback

List session days, exercise variations, the existing progression rule and a difficult-week alternative. Add food-access and recovery arrangements that make the routine feasible. Include a reason to pause or seek help rather than using the calendar as the sole authority.

## Choose evidence of progress

Use a repeatable submaximal task and notes about practicality. Review at planned intervals and when circumstances change. If a goal requires expertise beyond the course, identify the relevant professional or learning resource.

## Public case study

This page is the public case study for the Scientific Literature Intelligence Agent.

## Problem and approach

Build a local literature workflow that makes query approval, retrieval, source snapshots, normalization, deduplication, and later appraisal inspectable. Stage 2A accepts a human-authored PubMed query and produces a normalized candidate corpus with retained raw responses/provenance, resumable caching, and immutable artifacts. A separate appraisal foundation validates human-authored records and renders them without making scientific judgments.

## Appraisal foundation

Structured records can hold source snapshots and hashes, quoted passages, measurements, participant accounting, claim appraisals, citation-use audits, reviewer assessments, uncertainty, and reasoned checks. This is a data and review structure, not automated appraisal. No screening, scientific synthesis, live full-text or citation retrieval, or LLM appraisal is implemented.

## Evidence

A recorded live acquisition returned 68 records: 61 with abstracts and 68 with DOI values, with no retrieval failures; one exact-title collision with differing identifiers was retained as uncertain. Its Stage 2A acceptance record reports 23 offline tests and one live integration test passing. A later offline run after duplicate grouping reports 25 tests passing and unchanged hashes for acquisition files. These are historical results, not rerun for this portfolio update. On 2026-09-23, the focused appraisal test file passed (14 tests); this is software validation for those cases, not scientific validation or full-suite/live evidence.
